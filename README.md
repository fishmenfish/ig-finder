# Instagram Non-Followers Finder

![Anime-style mascot](https://api.dicebear.com/9.x/adventurer/svg?seed=ig-finder)

Find Instagram accounts that do not follow you back.

## Install

1. Install Tampermonkey.
2. Open `ig-finder.user.js`.
3. Copy all code into a new Tampermonkey script.
4. Save. Open Instagram.

## Use

1. Open the **Non-followers** panel.
2. Choose how many accounts to check.
3. Click **Start scan**.
4. Review results.
5. Select accounts before unfollowing.

Search, filters, whitelist, pause, stop, saved results, and CSV export are included.

## Files

- `ig-finder.user.js` — install this file.
- `README.md` — this guide.
- `.gitignore` — hides local files.

## Notes

Instagram can change its private endpoints. Results are a snapshot. Delays do not guarantee protection from limits.
